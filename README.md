# Site Hugo Martins – Desenvolvimento de Potencial Humano

Site institucional estático (Astro).

- `public/` e `src/`: o que vai ao ar.
- `scripts/`: trava de conteúdo pendente, conferência de links e de rastreadores.
- `docs/`, `brand/` e `conteudo-bruto/`: fontes internas (spec, pendências, marca original, textos brutos). Ficam só na máquina de quem desenvolve; o repositório público versiona apenas os READMEs dessas pastas.
