# brand/hugo-martins

Identidade visual Hugo Martins (2020), extraída de `Identidade Visual - Hugo Martins.zip` sem alteração (só os nomes de arquivo foram corrigidos: o zip vinha com acentos corrompidos).

- `IDENTIDADE_VISUAL_COMPLETA.pdf`: manual, 16 páginas. **Página 14 é da Holos Consultant (descontinuada): ignorar.** Paleta na p. 15, tipografia (Typeface 6781, P22 Underground) na p. 16.
- `LOGOPRINCIPAL_*`, `LOGO_*_VARIAÇÃO`: logo principal (cérebro circuito/orgânico + "HUGO MARTINS · desenvolvimento de potencial humano").
- `SUBMARCA_*`: o cérebro sozinho, sem texto.
- `PATTERN.jpg`: padrão de fundo (spec 9.1).
- `CURVAS.cdr` e `Cópia_de_segurança_de_CURVAS.cdr`: vetor original em CorelDRAW (vetorização para SVG pendente).
- `_descontinuado-holos/`: logo Holos, não usar.
